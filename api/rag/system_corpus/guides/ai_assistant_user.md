# AI-ассистент (для пользователя)

Раздел **AI Hub / AI-ассистент** помогает отвечать на вопросы о работе системы и работать с загруженными документами.

## Что умеет обычный чат

- Подсказать, **где в интерфейсе** найти раздел (меню, профиль, настройки).
- Объяснить, **что делают** доступные модули и типичные действия.
- Ответить про роли, пользователей и доступ — если у вас есть права администратора или это описано в справке.

## Документы

В режиме работы с документами можно:

- загрузить файл (Word, PDF, текст);
- задать вопросы по содержимому;
- при включённой векторизации — искать ответы точнее по фрагментам файла.

## Ограничения

- Ассистент опирается на справку о функционале системы и ваши файлы. Он **не заменяет** права доступа: если раздела нет в меню, нужен администратор.
- Не просит пароли и секреты. Не выдумывает несуществующие кнопки и экраны.
- Вопросы про установку сервера, код и команды разработчика — не его задача; для этого есть документация для специалистов.
