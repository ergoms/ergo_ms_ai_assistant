# С чего начать в ERGO MS

ERGO MS — веб-система с боковым меню разделов и личным кабинетом.

## Основные элементы

- **Боковое меню** — список разделов системы. Пункты зависят от вашей роли: то, к чему нет доступа, не показывается или недоступно.
- **Шапка** — уведомления, меню приложений, настройки профиля и выход.
- **Личный кабинет / Профиль** — данные учётной записи, язык, тема оформления, уведомления.

## Типичные задачи пользователя

1. Войти в систему логином и паролем (или по приглашению, если так настроено).
2. Открыть нужный раздел в боковом меню.
3. При необходимости изменить профиль и тему в настройках.
4. Следить за уведомлениями в шапке.

## Если раздела нет в меню

Скорее всего, у вашей роли нет доступа. Обратитесь к администратору системы — он может выдать роль или право на модуль.
