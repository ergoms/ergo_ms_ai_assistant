# Профиль и настройки

## Где найти

Откройте меню пользователя в шапке → **Профиль** / **Настройки** (или раздел «Личный кабинет» в меню, если он есть).

## Что можно настроить

- **Данные профиля** — имя, контакты и другие поля, доступные вашей организации.
- **Язык интерфейса** — русский, английский или французский (в системных настройках).
- **Тема оформления** — светлая, тёмная или автоматически по системе.
- **Уведомления** — какие события показывать в колокольчике шапки.
- **Параметры доступности** — при наличии: контраст, анимации, отображение изображений.

## Смена пароля

Обычно выполняется в настройках профиля или через форму «Забыл пароль» на экране входа. Если пункта нет — попросите администратора сбросить пароль.
