# AI-ассистент: чат и документы

Раздел **AI Hub / AI-ассистент** помогает с вопросами о работе системы и с загруженными файлами.

## Обычный чат

- Спросите, **где в интерфейсе** найти раздел (меню, профиль, настройки).
- Уточните, **что делают** доступные модули и типичные действия.
- Спросите про роли и доступ — если у вас есть права администратора или это есть в справке.

Открывается из бокового меню или меню приложений в шапке (при наличии права просмотра).

## Работа с документами

1. Загрузите файл (Word, PDF, текст) через кнопку загрузки.
2. Задайте вопросы по содержимому.
3. При включённой векторизации поиск по фрагментам файла точнее.

## Ограничения

- Ассистент не выдаёт доступ к скрытым разделам — права назначает администратор.
- Не сообщайте пароли и секреты.
- Вопросы про установку сервера и исходный код — не для этого помощника.
